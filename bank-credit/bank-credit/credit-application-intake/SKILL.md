# Credit Application Intake

## Purpose

Assist credit administration staff in receiving and organizing credit application information into a structured administrative record.

## When to Use

Use this skill when:
- Receiving new credit applications.
- Recording applicant information.
- Organizing incoming application records.
- Preparing an initial credit application recap.

## Required Input

When available, use:
- Application reference number.
- Applicant name or authorized identifier.
- Credit product type.
- Application date.
- Requested credit amount.
- Applicant contact information.
- Application purpose.
- Supporting document list.
- Assigned administrative staff, if provided.

## Procedure

1. Review the application information provided.
2. Identify the application type.
3. Organize the available applicant information.
4. Check whether required intake fields are present.
5. Identify missing or unclear information.
6. Prepare a structured application intake record.
7. Assign a preliminary administrative status based on the provided workflow.
8. Present the record to authorized bank staff for verification.

## Output Format

Provide:
- Application reference.
- Applicant reference.
- Credit product type.
- Application date.
- Requested amount, if provided.
- Application purpose, if provided.
- Supporting documents received.
- Missing information.
- Initial administrative status.
- Follow-up requirements.

## Rules and Limitations

- Never invent applicant information.
- Do not treat intake registration as credit approval.
- Do not change official application records without authorization.
- Do not expose confidential customer information.
- Use synthetic applicant information in public examples and testing.
