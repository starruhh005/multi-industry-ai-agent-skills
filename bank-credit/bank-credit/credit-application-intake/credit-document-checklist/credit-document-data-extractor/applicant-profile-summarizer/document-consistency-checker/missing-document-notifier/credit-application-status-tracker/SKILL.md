# Credit Application Status Tracker

## Purpose

Assist credit administration staff in organizing application progress records, tracking administrative stages, and preparing status recaps for credit applications.

## When to Use

Use this skill when:
- Reviewing the status of credit applications.
- Preparing application progress recaps.
- Organizing pending applications.
- Identifying applications requiring administrative follow-up.
- Preparing status summaries for internal coordination.

## Required Input

When available, use:
- Application reference number.
- Applicant reference.
- Credit product type.
- Application submission date.
- Current processing status.
- Status update date.
- Administrative notes.
- Assigned staff or unit.
- Follow-up requirements.

## Procedure

1. Review the application records provided.
2. Identify each application reference.
3. Organize applications according to their recorded status.
4. Check whether status information and dates are available.
5. Identify pending applications and required administrative follow-ups.
6. Flag records with missing status updates or unclear information.
7. Prepare an application status recap.
8. Present the recap to authorized bank staff for review.

## Suggested Administrative Status Categories

Use the bank's official status categories whenever available. If no official categories are supplied, the following may be used as provisional administrative labels:

- Received.
- Document Checking.
- Incomplete Documents.
- Administrative Review.
- In Process.
- Pending Information.
- Completed — Administrative Stage.
- Requires Staff Verification.

These labels do not represent credit approval or rejection.

## Output Format

| Application Reference | Submission Date | Current Status | Last Update | Follow-Up |
|---|---|---|---|
| Application ID | Date | Status from provided data | Date | Required action |

Include:
- Total applications reviewed.
- Applications by status.
- Applications requiring follow-up.
- Records with missing updates.
- Notes about incomplete information.

## Rules and Limitations

- Do not invent application statuses.
- Do not mark an application as approved or rejected unless an official status is provided by authorized staff.
- Do not independently update banking systems.
- Do not promise processing times.
- Keep applicant information confidential.
- Use synthetic application data in public demonstrations.
