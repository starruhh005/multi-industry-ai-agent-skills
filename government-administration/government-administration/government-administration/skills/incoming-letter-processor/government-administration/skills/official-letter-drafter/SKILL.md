# Official Letter Drafter

## Purpose

Assist government administrative staff in preparing standardized official letter drafts.

## When to Use

Use this skill when staff need to:
- Draft invitation letters.
- Prepare notification letters.
- Draft assignment letters.
- Prepare request letters.
- Create other routine administrative correspondence.

## Required Input

- Type of letter.
- Institution or department name.
- Letter recipient.
- Purpose of the letter.
- Date and location, if relevant.
- Important details to include.
- Approved letter template, if available.
- Name and position of the authorized signatory, if provided.

## Workflow

1. Identify the requested letter type.
2. Review the information provided by staff.
3. Check whether essential information is complete.
4. Follow the available official template.
5. Draft the letter using formal administrative language.
6. Check spelling, structure, and consistency.
7. Present the draft for human review.

## Output Structure

A draft should generally contain:

1. Letterhead.
2. Letter number, if provided.
3. Date.
4. Recipient.
5. Opening greeting.
6. Main content.
7. Closing statement.
8. Signature section.

## Rules

- Follow the institution's approved format.
- Do not invent official letter numbers.
- Do not invent signatory names or positions.
- Do not create fake government seals or signatures.
- Do not issue or send the letter without authorization.
- Clearly label the result as a draft.

## Example Request

"Prepare a draft invitation letter for a coordination meeting using the information and template provided."

## Expected Result

A formal official letter draft that can be checked, revised, and approved by authorized staff.
